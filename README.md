# ✈️ EDA on Flight Price Data

This project performs an **Exploratory Data Analysis (EDA)** on flight price data to understand the key factors affecting airfare.  
It explores how variables like **airline**, **departure time**, **journey duration**, and **number of stops** influence ticket prices.

---

## 🧠 Project Overview

Airfare pricing is dynamic and influenced by multiple factors such as seasonality, route, airline reputation, and travel time.  
This project leverages **Python-based EDA techniques** to uncover insights and relationships within the flight dataset.

---

## 🎯 Objectives

- Analyze flight data to identify the most influential factors affecting ticket prices  
- Detect outliers, missing values, and perform data cleaning  
- Visualize distributions and relationships between different features  
- Derive actionable insights for airlines and travelers  

---

## 🧰 Tools & Libraries Used

- **Python (3.x)**  
- **Pandas** – Data cleaning and manipulation  
- **NumPy** – Numerical operations  
- **Matplotlib & Seaborn** – Visualization and correlation analysis  
- **Jupyter Notebook** – Interactive data analysis  

---

## 📊 Key Insights

1. **Airline Impact:** Premium airlines tend to have higher ticket prices compared to budget carriers.  
2. **Stops Influence:** Non-stop flights are significantly more expensive than those with 1 or more stops.  
3. **Departure Time:** Late-night or early-morning flights tend to be cheaper due to lower demand.  
4. **Journey Duration:** Prices increase with flight duration, but not always linearly.  
5. **Seasonal Trend:** Prices peak during holiday and festival seasons.
